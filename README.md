# 🌍 The Unknown World

### A locally powered AI text adventure

> **Built with Llama**

The Unknown World is an experimental AI-powered text adventure built with Python.

Explore an unfamiliar world, interact with your surroundings, make decisions, and experience a dynamically generated story.

Unlike traditional text adventure games, the story isn't entirely predefined. A locally running language model acts as the narrator, generating scenes and responding to the player's actions.

The game also uses a text-to-image model to generate illustrations of the current scene.

## ✨ Features

- **Dynamic storytelling:** Scenes are generated by a local language model.
- **Free-form actions:** Describe what you want your character to do.
- **Conversation history:** Previous messages are supplied to the model to help maintain continuity.
- **AI-generated illustrations:** Story scenes are converted into images.
- **Local inference:** No external AI API is required.
- **Automatic image model download:** The image model is downloaded from Hugging Face when first needed.
- **Terminal interface:** A simple, colourful interface powered by Rich.

## 🤖 AI Models

This project uses two pretrained AI models.

### 1. Llama 3.2 3B Instruct

**Original developer:** Meta

**Role:** Storytelling and language generation.

Llama is responsible for generating the adventure, describing environments, responding to player actions, and maintaining the conversation.

The project uses a quantized GGUF version of the model through `llama-cpp-python`.

Original model:
https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct

Expected local filename:

`llama-3.2-3b-instruct-q4_k_m.gguf`

**Model distribution:** The model weights are not included in this repository. Users must obtain a compatible GGUF conversion separately and comply with the applicable Meta licence and the converter's distribution terms.

The original model's licence does not automatically establish the licence of every third-party conversion.

### 2. Tiny SD

**Developer:** Segmind

**Role:** Text-to-image generation.

Tiny SD transforms descriptions of the current scene into visual illustrations.

Model:
https://huggingface.co/segmind/tiny-sd

The model is downloaded automatically through Hugging Face Diffusers during the first image-generation request.

Its published model licence is CreativeML OpenRAIL-M. Users must comply with its conditions and restrictions.

## 💻 Requirements

### Software

- Windows, Linux or macOS (Windows is the primary documented setup).
- Python 3.10 or newer.
- pip.
- Internet connection for the initial model downloads.
- A compatible GGUF language model.

### Hardware

The current implementation uses CPU inference for image generation.

A dedicated GPU is not required by the current code, although it may improve performance if GPU support is configured.

Recommended considerations:

- At least 8 GB RAM, with 16 GB or more preferable.
- Sufficient storage for the language model, image model and dependencies.
- An SSD for more comfortable loading times.
- A reasonably capable modern processor.

These are practical recommendations, not guaranteed minimum specifications. Actual performance depends on the system and model configuration.

## 📥 Installation

### Step 1: Install Python

Download Python:

https://www.python.org/downloads/

Python 3.10 or newer is recommended.

During Windows installation, enable the option to add Python to PATH.

Verify the installation:

```bash
python --version
```

### Step 2: Download this repository

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Or download the repository as a ZIP file through GitHub.

Open a terminal inside the project folder.

### Step 3: Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

On Linux/macOS:

```bash
source .venv/bin/activate
```

### Step 4: Install PyTorch

The current project runs its image-generation pipeline on the CPU.

For a CPU-only PyTorch installation, use:

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
```

Official installation guide:

https://pytorch.org/get-started/locally/

### Step 5: Install project dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

**Windows note:** `llama-cpp-python` may require a compatible prebuilt wheel or a C/C++ build environment. If installation fails, consult its official installation documentation:

https://llama-cpp-python.readthedocs.io/en/stable/

### Step 6: Obtain the language model

Obtain a compatible GGUF conversion of Llama 3.2 3B Instruct.

The expected filename is:

`llama-3.2-3b-instruct-q4_k_m.gguf`

Place it inside the `AI` directory.

The final structure should look like this:

```text
The-Unknown-World/
│
├── main.py
├── README.md
├── requirements.txt
├── NOTICE
├── .gitignore
│
├── AI/
│   └── llama-3.2-3b-instruct-q4_k_m.gguf
│
└── generated_images/
```

The model file is intentionally excluded from this GitHub repository.

Make sure the filename matches the path in `main.py`.

### Step 7: Start the game

Run:

```bash
python main.py
```

The language model loads first.

The image-generation model is loaded when the first illustration is requested.

On its first use, Tiny SD downloads its required files from Hugging Face. An internet connection is therefore needed for this initial download.

## 🎮 How to Play

The game begins by generating an opening scene.

After reading the scene, enter an action in the terminal.

Example:

```text
Your action > I carefully examine the abandoned building.
```

The language model generates the next part of the adventure.

You can describe actions in your own words rather than selecting from a fixed menu.

To exit:

```text
quit
```

or:

```text
exit
```

## 🖼️ Image Generation

The game uses Segmind Tiny SD through Hugging Face Diffusers.

Current configuration:

| Setting | Value |
|---|---|
| Model | segmind/tiny-sd |
| Image width | 480 pixels |
| Image height | 480 pixels |
| Inference steps | 6 |
| Processing device | CPU |
| Image format | PNG |
| Output folder | generated_images |

The generated image is saved as:

`generated_images/scene.png`

The terminal also displays a smaller version using ANSI true-colour characters.

The current implementation overwrites the previous scene image.

## ⚠️ Known Limitations

This is an experimental project.

- AI-generated stories may contain inconsistencies.
- The model can misunderstand player actions.
- Story continuity is limited by the available context window.
- Image generation can be slow on CPUs.
- Generated images may not perfectly represent the written scene.
- The terminal interface is not a graphical game interface.
- The game currently has no dedicated save/load system.
- The image model requires an initial download.
- The current image display uses ANSI terminal colour support.

## 🛠️ Troubleshooting

### `ModuleNotFoundError`

Make sure the virtual environment is activated and install the dependencies:

```bash
pip install -r requirements.txt
```

### Language model file not found

Check that the GGUF file is inside the `AI` directory and has the exact expected filename.

### `llama-cpp-python` installation fails

Check its official installation instructions for compatible Windows wheels or compiler requirements.

https://llama-cpp-python.readthedocs.io/en/stable/

### Image generation fails

Check your internet connection during the first model download.

Also ensure that PyTorch, Diffusers and their dependencies installed correctly.

### Image generation is extremely slow

The current implementation uses CPU processing. Image generation speed depends heavily on the processor and available memory.

The goal is to explore what becomes possible when a player can interact with a dynamically generated world instead of following a completely predefined story.
