# THE UNKNOWN WORLD
### An AI-Powered Text Adventure

**Built with Llama**

The Unknown World is an experimental, locally running AI-powered text adventure built with Python.

Explore an unfamiliar world, interact with your surroundings, make decisions, and experience a dynamically generated story.

Unlike traditional text adventure games, the story isn't entirely predefined. An AI language model acts as the narrator, creating scenes and responding to the player's actions.

The experience is further enhanced by AI-generated illustrations that bring the described environments to life.

## Features

- **Dynamic Storytelling:** Stories and scenes are generated by an AI language model.
- **Player Freedom:** Describe your own actions instead of selecting from predefined options.
- **Conversation History:** Previous interactions are supplied to the language model to help maintain story continuity.
- **AI-Generated Illustrations:** Scenes are transformed into images using a text-to-image model.
- **Local AI Processing:** Both AI models run on your computer.
- **Automatic Image Model Download:** The image-generation model is downloaded automatically when first needed.
- **Terminal Interface:** A clean and colourful interface powered by Rich.

## The AI Models Behind the Project

This project builds upon the work of researchers, engineers and developers who have made powerful AI technologies accessible to independent developers.

### 1. Llama 3.2 3B Instruct

**Created by:** Meta

**Purpose:** Storytelling and language generation.

Llama is the intelligence behind the adventure. It generates the story, describes environments, responds to player actions and attempts to maintain continuity.

The project uses a quantized GGUF version through llama.cpp and llama-cpp-python.

Original model:
https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct

Expected model filename:

`llama-3.2-3b-instruct-q4_k_m.gguf`

**Important:** The model weights are not included in this repository. Users must obtain a compatible GGUF conversion separately and follow the applicable licences and distribution conditions.

The original model was developed by Meta. The creator and distributor of the particular GGUF conversion should also be credited according to its source and terms.

### 2. Tiny SD

**Created by:** Segmind

**Purpose:** Image generation.

Tiny SD transforms descriptions of the current scene into visual illustrations.

Model:
https://huggingface.co/segmind/tiny-sd

The model is downloaded automatically through Hugging Face Diffusers when image generation is first requested.

Its published licence is CreativeML OpenRAIL-M.

## Requirements

### Software

- Windows, Linux or macOS.
- Python 3.10 or newer.
- pip.
- A compatible GGUF language model.
- Internet connection for initial model downloads.

Windows is the primary documented setup.

### Hardware

The current implementation uses CPU processing for image generation.

Recommended:
- 16 GB RAM or more for a more comfortable experience.
- An SSD for model storage and loading.
- A reasonably capable modern processor.
- Sufficient free storage for the language model, image model and dependencies.

These are recommendations, not guaranteed minimum specifications. Actual performance depends on your hardware and model configuration.

A dedicated GPU is not required by the current code, although GPU acceleration could improve performance if configured.

## Installation Guide

### Step 1: Install Python

Download Python:

https://www.python.org/downloads/

Python 3.10 or newer is recommended.

During Windows installation, enable the option to add Python to PATH.

Verify your installation:

```bash
python --version
```

### Step 2: Download the Project

Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Alternatively, download the repository as a ZIP file through GitHub.

Open a terminal inside the project directory.

### Step 3: Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

On Linux/macOS:

```bash
source .venv/bin/activate
```

### Step 4: Install PyTorch

The current implementation uses CPU inference for image generation.

Install the CPU version:

```bash
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
```

Official installation guide:

https://pytorch.org/get-started/locally/

### Step 5: Install Dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

**Windows note:** llama-cpp-python may require a compatible prebuilt wheel or a C/C++ build environment. Follow its official installation instructions if installation fails:

https://llama-cpp-python.readthedocs.io/en/stable/

### Step 6: Obtain the Language Model

Obtain a compatible GGUF conversion of Llama 3.2 3B Instruct.

Expected filename:

`llama-3.2-3b-instruct-q4_k_m.gguf`

Create an `AI` folder inside the project directory and place the model inside it.

The directory should look like this:

```text
The-Unknown-World/
│
├── main.py
├── README.md
├── requirements.txt
├── NOTICE
├── .gitignore
│
├── AI/
│   └── llama-3.2-3b-instruct-q4_k_m.gguf
│
└── generated_images/
```

The model weights are intentionally not included in this GitHub repository.

Make sure the filename matches the path specified in `main.py`.

### Step 7: Run the Game

```bash
python main.py
```

The language model loads first.

The image-generation model is loaded when the first illustration is requested.

On its first use, Tiny SD downloads its required files from Hugging Face.

An internet connection is required for this initial download.

## Gameplay

The adventure begins with an AI-generated opening scene.

After reading the scene, enter an action in the terminal.

Example:

```text
Your action > I carefully examine the abandoned building.
```

The language model processes your action and generates the next scene.

You can describe actions freely instead of selecting from predefined menus.

To exit the game:

```text
quit
```

or:

```text
exit
```

## Image Generation

The image-generation system uses Segmind Tiny SD through Hugging Face Diffusers.

Current configuration:

| Setting | Value |
|---|---|
| Model | segmind/tiny-sd |
| Image width | 480 pixels |
| Image height | 480 pixels |
| Inference steps | 6 |
| Device | CPU |
| Image format | PNG |
| Output directory | generated_images |

Generated illustrations are saved as:

`generated_images/scene.png`

The terminal also displays a resized version using ANSI true-colour characters.

The current implementation overwrites the previous scene image.

## Known Limitations

This is an experimental project.

- AI-generated stories may occasionally contain inconsistencies.
- The language model may misunderstand player actions.
- Story continuity is limited by the available context window.
- Image generation can be slow on CPUs.
- Generated images may not perfectly represent the written descriptions.
- The game currently uses a terminal interface rather than a graphical interface.
- There is currently no dedicated save/load system.
- The image model requires an initial download.

## Troubleshooting

### ModuleNotFoundError

Activate your virtual environment and install the dependencies:

```bash
pip install -r requirements.txt
```

### Language Model Not Found

Check that the GGUF file is inside the `AI` folder and has the exact expected filename.

### llama-cpp-python Installation Problems

Consult the official documentation:

https://llama-cpp-python.readthedocs.io/en/stable/

### Image Generation Problems

Check your internet connection during the initial download.

Ensure that PyTorch, Diffusers and their dependencies installed correctly.

### Slow Image Generation

The current implementation uses CPU processing. Image-generation speed depends heavily on your processor and available memory.
