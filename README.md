
# THE UNKNOWN WORLD

An AI-powered, text-based adventure game set in a mysterious post-apocalyptic world.

Explore an unknown world, interact with your surroundings, and experience stories generated by locally running AI models.

## Features

- AI-generated stories and descriptions
- Interactive player choices
- Locally running language model
- AI-generated scene illustrations
- Terminal-based game interface

## AI Models

### Llama 3.2 3B Instruct
**Developer:** Meta Platforms

Used to generate stories, describe environments, and respond to player actions.

The model weights are not included in this repository. You must download the GGUF version separately.

**Required filename:**
`llama-3.2-3b-instruct-q4_k_m.gguf`

**Model:** https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct

### Tiny-SD
**Developer:** Segmind

Used to generate illustrations of the game's environments.

The model is downloaded automatically through Hugging Face when the game runs.

**Model:** https://huggingface.co/segmind/tiny-sd

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Sanu-Kumar-Equinox/AI-text-based-adventure-game.git
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Set up the Llama model

Create a folder named `AI` in the project directory.

Place the downloaded GGUF model inside it:

```text
AI/
└── llama-3.2-3b-instruct-q4_k_m.gguf
```

### 4. Run the game

```bash
python main.py
```

## Requirements

- Python

- Sufficient RAM and storage
- Compatible llama-cpp-python installation
